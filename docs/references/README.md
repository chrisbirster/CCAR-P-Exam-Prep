# References

This folder is the evidence layer for the CCAR-P study notes.

Each concept in `docs/concepts/` links here. Reference pages summarize what an official source supports and then link to the original source.

## Evidence policy

- **Exam scope** comes from the CCAR-P v1.0 exam blueprint.
- **Claude product/engineering behavior** should come from current Anthropic first-party documentation or engineering/research posts.
- **MCP protocol behavior** should come from the current MCP specification.
- **Architecture heuristics** are labeled as interpretation when they go beyond explicit source wording.
- **Time-sensitive facts** must include a verification date.

Reference notes are summaries and attribution aids; they are not copies of the source documents.
