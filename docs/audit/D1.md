## Review workflow

For each objective:

1. Read the exam subject.
2. Read the primary source sections.
3. Check the secondary blueprint cross-check.
4. Compare the sources with our study note.
5. Give one verdict: **GOOD**, **GOOD WITH INTERPRETATION**, **CHANGE**, or **NOT GOOD**.
6. Only approved/corrected objectives can feed final flashcards.

## Interpretation note

A source packet may intentionally label part of a study note as **architecture interpretation**. That is not automatically an error. It means the guidance is useful professional reasoning but should not be represented in flashcards as a verbatim Anthropic rule.
