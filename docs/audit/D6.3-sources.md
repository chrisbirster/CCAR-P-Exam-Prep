## 2. Primary source — Demystifying Evals

[Demystifying Evals](../references/demystifying-evals.md)

Anthropic treats evaluation as an iterative production lifecycle and supports using evidence from real behavior to improve the system.

## 3. Direct evidence vs. interpretation

**Directly supported:**
- iterative evaluation;
- production feedback should inform improvement;
- system behavior needs measurable evaluation.

**Architecture interpretation:**
- our feedback-loop structure: signal → trigger → owner → investigation → action → verification;
- quality/latency/availability/cost/escalation expectation categories;
- iterate vs. re-architect decision rule;
- a thumbs-down is a signal, not a complete evaluation.

## 4. Current note under review

Our note recommends measurable expectations, named owners, explicit triggers, and evidence-driven iteration rather than promises of perfect AI behavior.
