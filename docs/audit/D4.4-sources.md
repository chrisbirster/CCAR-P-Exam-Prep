## 3. Direct evidence vs. interpretation

**Directly supported:**
- inspect trajectories for intermediate failures;
- external outcomes can expose discrepancies between model claims and actual state;
- regression evaluations protect known behavior.

**Architecture interpretation:**
- our taxonomy: prompt, retrieval, model mismatch, tool, orchestration, data drift, model/version drift;
- diagnostic sequence symptom → reproduce → inspect trace → isolate → fix → regression;
- "hallucination" should not be a catch-all diagnosis.
