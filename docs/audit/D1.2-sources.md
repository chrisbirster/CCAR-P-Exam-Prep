## 1. Exam subject

The blueprint explicitly tests end-to-end architecture rather than isolated model prompting.

## 2. Primary source — Effective Context Engineering

[Effective Context Engineering](../references/effective-context-engineering.md)

Anthropic describes long-running systems that manage context, structured notes/state, retrieval, and subagent isolation. This supports the idea that production architecture is broader than one model call.

## 3. Primary source — Demystifying Evals

[Demystifying Evals](../references/demystifying-evals.md)

Anthropic emphasizes external outcomes, trajectories, and system-level evaluation. This supports observing whether the overall request path achieved the intended state, not merely whether the model produced plausible prose.

## 4. Direct evidence vs. interpretation

**Directly supported:**
- agent systems have multiple turns/tools/state;
- external outcomes can be more authoritative than model claims;
- context and application state should be handled deliberately.

**Architecture interpretation:**
- our specific reference flow of auth → validation → retrieval → model → tools → verification → output → telemetry;
- system-of-record guidance;
- retry/idempotency/fail-closed rules.

## 5. Current note under review

Our note teaches whole-request-path design, explicit state ownership, failure paths, retries, authorization boundaries, observability, and authoritative systems of record.
