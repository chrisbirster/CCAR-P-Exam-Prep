## 2. Primary source — Demystifying Evals

[Demystifying Evals](../references/demystifying-evals.md)

Anthropic frames evaluation as an iterative lifecycle rather than a one-time launch gate. Changes should be tested and regressions detected as the system evolves.

## 3. Direct evidence vs. interpretation

**Directly supported:**
- iterative evaluation matters;
- changes need evidence;
- regressions should be caught.

**Standard experimentation practice / interpretation:**
- hypothesis, primary metric, guardrail metric, assignment strategy, stopping rule;
- session/user-level consistency;
- statistical vs. practical significance;
- shadow testing definition and recommended use cases.

These are sound experimentation concepts but are not all explicitly established by the Anthropic eval article.

## 4. Current note under review

Our note teaches controlled experimentation, guardrails, shadow testing, and avoiding multiple simultaneous uncontrolled changes.
