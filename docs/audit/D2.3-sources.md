## 3. Important time-sensitive distinction

The **blueprint** may name chain-of-thought as a concept, but current Claude models can use native/adaptive thinking. Manual "show every step" prompting should not be taught as a universal production best practice.

## 4. Direct evidence vs. interpretation

**Directly supported:**
- examples can improve consistency;
- structured prompts can help complex instructions;
- thinking guidance depends on model generation.

**Architecture interpretation:**
- start with the lightest technique that passes evals;
- avoid examples when zero-shot already meets requirements;
- solve retrieval/data failures at the right layer rather than endlessly rewriting prompts.
