# D4.2 Sources — Evaluation Datasets and Frameworks

**Objective:** Design evaluation datasets and test frameworks using mixed methodologies  
**Audit status:** HUMAN APPROVED

## 1. Exam subject

The blueprint explicitly tests evaluation datasets/frameworks.

## 2. Primary source — Demystifying Evals

[Demystifying Evals](../references/demystifying-evals.md)

Anthropic defines useful evaluation concepts including:
- tasks;
- trials;
- graders;
- transcripts/trajectories;
- outcomes;
- suites/harnesses.

The source also supports using deterministic, model-based, and human grading depending on the property being measured.

## 3. Direct evidence vs. interpretation

**Directly supported:**
- repeated trials can matter for stochastic agents;
- deterministic graders are useful when exact state can be checked;
- model graders and human review are appropriate for harder subjective criteria;
- agent trajectories and external outcomes can matter.

**Architecture interpretation:**
- our exact "grader hierarchy";
- include routine, boundary, adversarial, malformed, historical, and multi-turn cases;
- calibrate model graders against human labels.

## 4. Current note under review

Our note recommends representative datasets, multiple grader types, external-state checks, repeated trials, and converting production failures into regression cases.
