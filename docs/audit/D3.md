## Review workflow

For each subject:

1. Read the **exam subject**.
2. Read the **primary source sections**.
3. Read the **secondary blueprint cross-check**.
4. Compare those sources with the **current study note**.
5. Give one human verdict:

```text
GOOD
GOOD WITH INTERPRETATION
CHANGE
NOT GOOD
```

6. Only after the human verdict:
   - update the study note if needed;
   - record the verdict;
   - mark the objective complete;
   - allow that objective to feed final flashcards.
