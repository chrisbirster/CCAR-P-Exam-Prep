# D4.1 Sources — Evaluation Metrics

**Objective:** Define evaluation metrics including accuracy, latency, cost, safety, and security  
**Audit status:** HUMAN APPROVED

## 1. Exam subject

The blueprint explicitly asks candidates to define evaluation metrics across quality and operational dimensions.

## 2. Primary source — Demystifying Evals for AI Agents

[Demystifying Evals](../references/demystifying-evals.md)

Anthropic describes agent evaluation using tasks, trials, graders, trajectories, and outcomes. It emphasizes that agent systems cannot be judged reliably by one final-answer score alone.

## 3. Direct evidence vs. interpretation

**Directly supported:**
- multiple evaluation dimensions are needed for agents;
- outcomes and trajectories matter;
- graders should match what is being measured.

**Architecture interpretation:**
- our specific list of quality/operational/business metrics;
- requiring every metric to have a target and owner;
- use hard floors for safety/security.

## 4. Current note under review

Our note says vague goals like "good responses" must become observable metrics and thresholds, and recommends balancing task quality, latency, cost, safety, security, and business outcomes.
