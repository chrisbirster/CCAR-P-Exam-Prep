# D1.3 Sources — Architectural Patterns

**Objective:** Select appropriate architectural patterns: workflow, agentic, augmented LLM, and hybrids  
**Audit status:** HUMAN APPROVED

## 1. Exam subject

The blueprint explicitly asks candidates to choose appropriate architecture patterns.

## 2. Primary source — Building Effective AI Agents

[Building Effective AI Agents](../references/building-effective-ai-agents.md)

Anthropic explicitly distinguishes **workflows** from **agents**:
- workflows use predefined code paths;
- agents dynamically decide how to use tools/processes.

The article also describes prompt chaining, routing, parallelization, orchestrator-workers, and evaluator-optimizer patterns.

## 3. Direct evidence vs. interpretation

**Directly supported:**
- workflows vs. agents distinction;
- named composable workflow patterns;
- preference for adding complexity only when justified.

**Architecture interpretation:**
- "prefer the least autonomous pattern that meets the requirement";
- our augmented-LLM/workflow/agent/hybrid decision checklist;
- claims about observability/latency trade-offs are systems reasoning, not formal Anthropic rules.

## 4. Current note under review

Our note compares:
- single augmented model call;
- deterministic workflow;
- agent;
- hybrid architecture.

It recommends escalating autonomy only when evaluation shows measurable benefit.
