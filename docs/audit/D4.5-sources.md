The blueprint explicitly tests optimization across token use, latency, and cost-performance.

## 2. Primary source — Effective Context Engineering

[Effective Context Engineering](../references/effective-context-engineering.md)

## 3. Primary source — Advanced Tool Use

[Advanced Tool Use](../references/advanced-tool-use.md)

Anthropic describes programmatic tool use and on-demand discovery as ways to reduce context overhead and unnecessary model-visible intermediate data.

## 4. Primary source — Writing Effective Tools

[Writing Effective Tools](../references/writing-effective-tools.md)

Anthropic recommends high-signal tool responses and efficient tool interfaces.

## 5. Direct evidence vs. interpretation

**Directly supported:**
- context/tool overhead affects efficiency;
- programmatic processing can reduce repeated model interaction;
- tool responses should avoid unnecessary context.

**Architecture interpretation:**
- cost per successful outcome is better than cost per request;
- p50/p95/p99 tracking;
- routing, batching, cache/freshness decisions;
- smaller model only when quality threshold still passes.

## 6. Current note under review

Our note lists model routing, caching, shorter context, JIT retrieval, fewer model calls, parallelism, batching, and programmatic tool-result processing as optimization levers.
