## 2. Primary source — Effective Context Engineering

[Effective Context Engineering](../references/effective-context-engineering.md)

Anthropic describes context as finite and emphasizes:
- just-in-time retrieval;
- compaction;
- structured note-taking;
- externalized state;
- context isolation.

## 3. Direct evidence vs. interpretation

**Directly supported:**
- more context is not automatically better;
- context is a finite working resource;
- just-in-time loading and compaction are useful;
- subagent isolation can reduce context interference.

**Architecture interpretation:**
- our four-way distinction: active context, retrieval, application state, memory/summary;
- "context window is a working set, not a database";
- preserve specific classes of information during compaction.

## 4. Current note under review

Our note teaches selective context, just-in-time retrieval, compaction, external state, and isolation rather than preloading everything.
