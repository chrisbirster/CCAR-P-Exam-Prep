# Flashcards

The CCAR-P deck targets **2,000 generated Deez cards**.

See [the flashcard plan](../docs/flashcard-plan.md) for domain weights, note-type allocation, quality rules, tagging, and the one-week review strategy.

Generated deck artifacts will live here.

Planned outputs:

- `ccar-p.nut` — shareable Deez deck
- `ccar-p-api.json` — bulk API payload source
- `batches/` — smaller import batches for recovery and auditing

The deck must contain only original study material derived from public exam objectives and legitimate public preparation material. Do not contribute reconstructed or confidential live exam questions.
